# Коты в Telegram

Игра, где котами на поле управляют через Telegram-бота.

Три программы:

- `server.py` — сервер на Flask с базой (SQLAlchemy + sqlite)
- `game.py` — окно игры на pgzero
- `bot.py` — Telegram-бот

Игрок пишет боту `/join`, в ответ приходит клавиатура со стрелками. Стрелки шлют
команды на сервер, сервер двигает кота и сохраняет всё в базу. Окно игры
опрашивает сервер и рисует котов и монетку. Подобрал монетку — она появляется
в новом месте.

## Запуск

Поставить зависимости:

```bash
pip install -r requirements.txt
```

Вписать токен бота от @BotFather в `.env.local`:

```
TELEGRAM_BOT_TOKEN=твой_токен
```

И запустить три программы в трёх терминалах:

```bash
python server.py
python game.py
python bot.py
```

Сервер поднимается на http://127.0.0.1:8000. Там же есть таблица лидеров
(`/leaderboard`) и страница про опыт в ИИ (`/`).

## Настройки

`.env` — обычные настройки (адрес сервера, размер поля), `.env.local` — токен.
Спрайты кота лежат в `images/`.
